# data/ — контент игры

Всё контентное описано здесь, а не в коде. `Registry` (`src/core/registry/`) загружает каталог при старте игры.

## Раскладка

```
data/<категория>.json          базовые записи категории
data/<категория>/*.json        дополнения; грузятся после базового файла, по алфавиту
data/schemas/<категория>.json  схема категории
```

Категория определяется по имени файла или папки. Если у категории нет схемы, её записи грузятся без проверки, и в лог пишется предупреждение. У `blocks` схема обязательна.

## Формат файла

```json
{ "format": 1, "entries": [ { "id": "granite", "...": "..." } ] }
```

- `id` записывается латиницей в нижнем регистре через `_` (`^[a-z][a-z0-9_]*$`) и уникален внутри категории.
- Если поле не указано, подставляется `default` из схемы.
- Неизвестные поля считаются ошибкой. Это защищает от опечаток вроде `colour` вместо `map_color`.

## Формат схемы

```json
{ "format": 1, "category": "blocks", "fields": { "<поле>": { "type": "...", ... } } }
```

| type | Параметры | Значение в игре |
|---|---|---|
| `string` | `pattern` (regex) | String |
| `int`, `float` | `min`, `max` | int / float |
| `bool` | | bool |
| `enum` | `values: [...]` | StringName |
| `localized` | | `{ "ru": "...", "en": "..." }`, оба перевода обязательны |
| `color` | | Color из `#rrggbb` / `#rrggbbaa` |
| `object` | `fields: {...}` | Dictionary |
| `array` | `of: {спецификация элемента}` | Array |
| `ref` | `to: ["blocks", "items"]` | StringName. Проверяется после загрузки всех категорий |

Общие ключи поля: `required`, `default`, `doc` (пояснение для людей).

## Блоки

Поля описаны в `schemas/blocks.json`. Важное:
- `air` (числовой ID 0) встроен в движок, объявлять его в данных нельзя.
- Числовые ID назначаются в порядке загрузки и действуют только в пределах одного запуска. В сохранения пишутся строковые ID через палитру, поэтому порядок записей можно менять.
- `render: opaque` означает, что блок закрывает соседние грани (отсечение в мешере). `cutout` подходит для листвы, `translucent` — для стекла и льда, `liquid` — для воды и лавы.
- `textures`: либо `all`, либо все три `top` / `bottom` / `side`. Конкретная сторона перекрывает `all`. Имя — текстурный набор: его рисует `tools/texgen/texgen.py` (рецепт выбирается по материалу, тегам и форме блока, см. `classify()`); после добавления нового набора перегенерируй атласы. Если набора нет, блок рисуется цветом `map_color`, а `test_block_textures` падает.
- `light_emission` (0–15) и `light_color` — свет блока (лава); `light_filter` — насколько блок гасит проходящий свет (0 — воздух, 1 — листва, 2 — вода, 15 — непрозрачный).
- `shape`: `cube` (по умолчанию), `cross` (растения — два перекрещенных квадрата), `layer` (тонкий слой высотой `layer_height`: снег, мох, кувшинка). Только непрозрачный куб закрывает соседние грани.
- `container: { slots, kind }` — хранилище (сундук, комод, бочка, ящик): число ячеек; содержимое сохраняется в region-файле.
- `drops` — что выпадает (id блока или предмета, `min`/`max`, `chance`); блок без `drops` ничего не даёт.
- Выживание (этап 5): `heat` — тепло рядом с блоком, °C (костёр 18, лава 30, факел 4; спадает с расстоянием до `heat_radius`); `contact_damage` — урон в секунду, если стоять в блоке; `bed: { kind, rest }` — кровать или спальник (сон, точка возрождения); `food` и `medicine` — как у предметов (съедобные грибы и травы, подорожник).
- Ремесло (этап 6): `station: { kind, tier }` — станция из data/stations.json; `model` — модель из коробок вместо куба (`from`/`to` в 1/16 блока, `tex` — блок, чья текстура, `anim` — вращение части); у станции `render: invisible` (куба нет, рисуется модель); `fuel: { heat, minutes }` — топливо. Псевдоблоки `tex_*` (`item: false`) — только текстуры для моделей.
- `tint`: `grass`/`foliage` — блок окрашивается цветом биома (палитра по сезонам) с плавным переходом между биомами; `tint_strength` — доля цвета биома.

Блоки разложены по файлам: `blocks.json` (базовые), `blocks/geology.json`, `ores.json`, `wood.json`, `plants.json`, `misc.json`.

## Мир (этап 2)

| Категория | Что описывает |
|---|---|
| `worldgen` | рельеф, климатические шумы, реки, озёра, пещеры |
| `world_types` | типы мира на экране создания (обычный, большие биомы, архипелаг, горный, плоский) |
| `biomes` | 38 биомов: категория рельефа, климатическая точка, температура, поверхность, сезонные палитры, деревья, растения, особенности, фауна, погода, звуки; `water_kind` — пресная, грязная или морская вода (этап 5) |
| `trees` | виды деревьев: блоки ствола и листвы, форма, высота, толщина ствола |
| `geology` | геологические провинции: осадочный чехол, фундамент, глубинный слой |
| `ores` | залежи: блок, форма (гнездо, жила, пласт, жеода, трубка, россыпь), породы-хозяева, глубина, провинции, биомы |
| `input_bindings` | управление по умолчанию |
| `items` | предметы (этап 4): вид, стак, вес, прочность, слот экипировки, рюкзак, инструмент, броня, тепло, еда, вид на модели (`model`) и иконка (`icon`). Блоки — тоже предметы (поле `item` блока, вес `weight`). Этап 5: `food { nutrition, thirst, spoil_days, hot, eat_seconds, effects[{id, chance}] }`, `medicine { cures[], chance, heal, applies[] }` |
| `materials` | материалы частей (этап 6): категория (stone, metal, wood, binding), уровень, скорость, прочность, острота, вес, гибкость, температура плавки, цвет; `sources`/`source_tags` — какие предметы этим материалом являются |
| `parts` | части инструментов: слот (head, handle, binding), категории материалов, сколько единиц материала, форма для мини-игры ковки (`forge_profile`). Часть — предмет с тем же id; материал и качество — в данных стопки |
| `tool_types` | инструменты и оружие из частей: какие части, чем ломает, базовые скорость, урон, прочность, род названия |
| `qualities` | 5 уровней качества: порог балла, множитель свойств, цвет |
| `alloys` | сплавы: результат, доли компонентов, допуск, жар, время на единицу |
| `stations` | виды станций: режим (process — по входам, recipe — выбор рецепта), ячейки, жар, мехи, вода, тепло, свет, эффекты, звук |
| `recipes` | рецепты (`data/recipes/*.json`): станция, op (craft, forge_part, alloy, assemble, quench, sharpen, dye, cook, repair, salvage), входы (id или tag; tag `ingot` — слитки одного металла), выход, время (игровые минуты), жар, мини-игра, открытие (default / ingredients / blueprint) |
| `survival` | константы выживания (этап 5, запись `default`): скорости голода и жажды, выносливость, регенерация, пороги температуры тела, комфорт, мокрость, воздух, падение, усталость, тепло, сезонные поправки температуры, шансы болезней |
| `effects` | болезни, баффы и дебаффы: стадии (длительность, множители голода/жажды/выносливости/скорости/регенерации, урон в час, жар, согрев, запрет бега, симптомы), шанс ухудшения, во что переходит (`next_effect`), лекарства, польза сна в кровати, текст лечения |
| `difficulties` | сложности: множители голода, жажды, урона, болезней, регенерации; смерть от голода, выпадение вещей, одна жизнь (хардкор) |
| `hairstyles`, `beards` | причёски и бороды редактора персонажа — коробки в «пикселях» головы 8×8×8 |
| `face_parts`, `face_presets` | черты лица (пиксели на текстуре лица 8×8) и готовые лица |
| `body_types`, `palettes` | пропорции типов тела; цвета кожи, волос, глаз, ткани |
| `settings` | все настройки раздела 19: тип, диапазон, варианты, раздел, с какого этапа работает (`stage`) — по ним строится экран |
| `graphics_presets` | пресеты графики Низкие / Средние / Высокие / Ультра (этап 3): дальность, LOD, тени, SSAO/SSIL, туман, glow, трава, сглаживание, масштаб рендера |

Новый биом, дерево, руда или порода добавляются только данными. Новая *форма* (дерева, залежи, модификатор рельефа) — это код в `src/world/gen/`.

Проверить данные: `scripts/check.sh`.
