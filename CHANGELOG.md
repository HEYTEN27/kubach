# CHANGELOG

## [0.1.0] — 2026-10-23 — Этап 1: ядро мира

### Добавлено
- Мир 30 000 × 576 блоков: `WorldConst`, `ChunkSection` (однородные секции — одно число), `ChunkColumn` (36 секций).
- `TerrainGenerator`: рельеф по сиду из `data/worldgen.json` (континентальность, эрозия, хребты, детали, сплайн высот), слои пород, почва, пляжи, дно, скалы, вода до уровня моря, материнская порода. `WorldSeed`: сид из текста.
- `GreedyMesher`: greedy meshing с отсечением граней, отдельная поверхность для воды и стекла, ранний выход для закрытого камня.
- `ChunkManager`: потоковая загрузка вокруг игрока, генерация и мешинг в `WorkerThreadPool`, бюджет применения мешей, выгрузка, приоритет для правок.
- `World`: доступ к блокам, слой действий `GameAction` → `execute()`, floating origin, граница мира (`WorldBorder`).
- Сохранения: `RegionStore` (region-файлы 32×32, zstd, палитра строковых ID, только изменённые колонны, атомарная запись), `WorldSave` (`world.json`).
- Игрок:
  - `VoxelBody` (AABB-коллизии в double), `PlayerMotor` (ходьба, бег, присед у края, ровно один прыжок на 1,25 блока, плавание, полёт);
  - `Player` (камера 1-е лицо, из-за плеча с коллизией, спереди; F5 переключает плавно);
  - `PlayerModel`, `BlockInteraction` (луч DDA `VoxelRaycast`, подсветка, ломание с удержанием, установка).
- UI: стартовое меню (создание и загрузка мира), HUD, отладочный экран F3, пауза.
- `data/input_bindings.json` и автозагрузка `Controls` (физические клавиши).
- Автозагрузка `Audio`: звуки шагов, ломания и установки из `assets/audio/sfx/`; если файла нет, звук тихо пропускается.
- Аргументы запуска: `--world`, `--seed`, `--creative`, `--view`, `--teleport`, `--look`, `--camera`, `--f3`, `--screenshot`, `--bench` (полёт с логом frametime).
- Бенчмарки: `terrain_column`, `mesh_surface_section`, `world_load_view12`.
- Тесты: 124 GUT (мир, мешер, генерация, сохранения, физика, луч, игрок в мире, floating origin на 14 900).

### Изменено
- `check.sh` и `test.sh` всегда переимпортируют проект: иначе новые `class_name` не видны.
- `check_project` загружает скрипты из кэша: перезагрузка без кэша ломала уже работающие скрипты.
- `ChunkSection.set_block()` копирует массив перед записью: в GDScript 4 packed-массивы передаются по ссылке.

## [0.0.1] — 2026-10-23 — Этап 0: каркас проекта

### Добавлено
- Проект Godot 4.7.2 (Forward+, запасной OpenGL 3): имя «Кубач», каталог сохранений `user://` → `Kubach`, иконка, стартовый экран `src/ui/boot/`.
- `CLAUDE.md`: правила проекта, структура, команды, методика проверки производительности без видеокарты.
- Автозагрузка `EventBus` — шина сигналов.
- Автозагрузка `Registry` (`ContentRegistry`): загрузка `data/`, расширения в `data/<категория>/`, проверка по схемам (`SchemaValidator`), значения по умолчанию, отложенная проверка ссылок, понятные ошибки с файлом и полем. Для блоков — `BlockDef`, числовые ID (0 — воздух) и плоские массивы `block_solid`, `block_opaque`, `block_light_emission`, `block_light_filter`.
- `data/schemas/blocks.json` и 10 блоков в `data/blocks.json`.
- Скрипты: `scripts/check.sh`, `test.sh`, `bench.sh`, `screenshot.sh`, `export_windows.sh`, `export_linux.sh`. Godot и шаблоны экспорта скачиваются автоматически, все запуски идут с таймаутом.
- GUT 9.7.1 (`addons/gut`), 52 теста: реестр на настоящих данных, 24 сценария ошибок данных, валидатор схем, сводка frametime, настройки проекта.
- `FrameTimeLogger` (режим `-- --bench=<сек>`): CSV и JSON-сводка frametime и счётчиков рендера. CPU-бенчмарки `tools/bench/` с эталоном и порогом регрессии 25%.
- Режим `-- --screenshot=<файл>` для визуальных смоук-тестов.
- Git LFS для бинарных ассетов, `assets/audio/MANIFEST.md`, `assets/audio/CREDITS.md`.
